# Jeansel Lantigua — Portfolio

One-page site for freelance web design and development. Sidebar identity, a browser mockup of live work, a Highbridge Voices case study, three service tiers, a four-step process, and a single email CTA.

## Files

| File         | Role                                      |
|--------------|-------------------------------------------|
| `index.html` | Markup and copy                           |
| `styles.css` | Layout, typography, and responsive styles |
| `script.js`  | Sidebar, scroll spy                       |
| `hbv-homepage.jpg` | Highbridge Voices homepage screenshot |

## Run locally

```bash
npx serve .
```

Then open the URL shown in the terminal (often `http://localhost:3000`).

## Customize

- Copy, prices, and links live in `index.html`.
- Colors and spacing live in `styles.css` (`:root`).
- The browser window shows the Highbridge Voices homepage (`hbv-homepage.jpg`). The live site is [highbridgevoices.org](https://www.highbridgevoices.org).
