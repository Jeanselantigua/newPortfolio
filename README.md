# Jeansel Lantigua — Portfolio

A static personal portfolio site: hero, about, skills, experience, projects, and contact. Built with plain HTML, CSS, and JavaScript—no build step or framework.

## Files

| File        | Role                                      |
| ----------- | ----------------------------------------- |
| `index.html` | Markup and section structure              |
| `styles.css` | Layout, typography, and responsive styles |
| `script.js`  | Mobile nav, scroll animations, counters   |

Optional assets referenced in the page: `resume.pdf`, and a profile image (see the hero photo placeholder in `index.html`).

## Run locally

Open `index.html` in a browser, or serve the folder with any static server, for example:

```bash
npx serve .
```

Then visit the URL shown in the terminal (often `http://localhost:3000`).

## Customize

- Edit copy and links in `index.html`.
- Adjust colors, spacing, and breakpoints in `styles.css`.
- Tweak interactions in `script.js`.
